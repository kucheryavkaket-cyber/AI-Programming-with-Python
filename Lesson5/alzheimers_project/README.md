# Аналіз даних пацієнтів

## Опис проєкту
Програма завантажує дані пацієнтів із CSV-файлу, перевіряє коректність віку та BMI, виконує розрахунки й формує текстовий звіт.

## Структура проєкту
- `main.py` — головний файл програми.
- `app/config.py` — налаштування шляхів до файлів.
- `app/data_loader.py` — завантаження даних.
- `app/services.py` — перевірки та розрахунки.
- `app/exceptions.py` — власний клас винятку.
- `app/report.py` — формування звіту.
- `data/` — папка з CSV-файлом.

## Використані технології
- Python
- Pandas
- pathlib

## Запуск програми
Перейти до папки `alzheimers_project` і виконати команду:

`python main.py`

## Обробка помилок
Програма обробляє відсутність файлу даних, некоректні значення BMI та вихід віку за встановлені межі.

## Джерело даних
За основу взято структуру Alzheimer's Disease Dataset — Rabie El Kharoua, Kaggle.

Для навчального проєкту використано 10 записів із набору. Значення в стовпцях було замінено на штучно створені дані. Ідентифікатори також змінено.

До набору додано два навмисно некоректні значення для перевірки обробки помилок програмою.
